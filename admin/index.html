Quick actions

Publish your changes

Edits made here are saved only in this browser as a draft. To show them to every visitor, update the site's content file:

  1. Click Download content.js.
  2. Replace js/content.js in the website folder with the downloaded file.
  3. Upload / deploy the website again (or commit it to GitHub if it is hosted there).
  4. Come back and click Discard edits so this browser shows the published copy again.

Backup

A JSON copy of everything (text, products, photos, settings). Use Import to restore it, or to move your edits to another computer.

Discard edits

Throws away the draft in this browser and goes back to the published content (js/content.js).
